# Smash-WM-Dashboard

## Project Structure

```text
projekt/
├── dashboard.py
├── requirements-dashboard.txt
├── data/
│   └── smash_wm.db
└── src/
    └── smash_statistics.py
```

## Installation

```bash
python3 -m pip install -r requirements-dashboard.txt
```

## Run

```bash
python3 -m streamlit run dashboard.py
```

Streamlit should then open the dashboard automatically in your browser.
